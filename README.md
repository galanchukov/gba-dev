# Деньги до аренды

Личный Android-трекер доходов, резерва на аренду и расходов.

## Возможности
- Учёт заработка за подработки.
- Отдельный резерв на аренду с целью 12 000 ₽.
- Учёт расходов на жизнь.
- История операций и отмена последней записи.
- Хранение данных локально на устройстве, работает без интернета.

## Сборка APK
GitHub Actions собирает debug APK при push в `main` или вручную через вкладку **Actions** → **Build Android APK** → **Run workflow**.

После успешной сборки открой запуск workflow и скачай артефакт `money-rent-tracker-debug-apk`.

Для установки debug APK на личный Android нужно разрешить установку приложений из выбранного источника. Это тестовая сборка, не опубликованный релиз.
